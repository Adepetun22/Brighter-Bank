Brighter Bank is a digital-first banking brand. This website serves as the primary public-facing platform for customers to:

- Explore personal, business, lending, mortgage, credit card, investing, and insurance products.
- Compare rates and features through interactive tools.
- Apply for accounts or check product eligibility.
- Access support, locate branches, and read company news.

### Core Principles

- **Optimism in Motion:** The 3D hero communicates the brand promise — a luminous bank rising with a glowing sun, symbolizing financial growth and security.
- **Design Consistency:** A full design system governs typography, spacing, colors, and component behavior across Desktop (1440px), Tablet (770px), and Mobile (440px).
- **Performance First:** 3D assets load lazily and fall back gracefully to static visuals on low-power devices. LCP targets under 2.5 seconds.
- **Accessible by Default:** WCAG 2.1 AA compliance with semantic HTML, focus indicators, and contrast ratios meeting 4.5:1 for text.

| **3D Rendering** | [Three.js](https://threejs.org/) |
| **Carousels / Sliders** | [Swiper](https://swiperjs.com/) |
| **Framework** (optional integration) | React / Next.js

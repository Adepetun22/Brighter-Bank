# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability in Brighter Bank, **do not open a public GitHub issue**.

Please report it privately to: security@brighterbank.com

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested remediation

We will acknowledge receipt within **48 hours** and aim to resolve critical issues within **7 days**.

## Scope

- Authentication & session management
- Account data exposure
- API authorization bypasses
- XSS / CSRF / injection vulnerabilities
- Sensitive data in logs or client-side storage
